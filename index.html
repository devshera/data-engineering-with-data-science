Curriculum

6 topic areas. 1 refreshable ETL project. Reliable data from week one.

A structured, four-week certificate section covering the practical ETL skills behind dependable data. Learn through demonstrations, guided practice, business cases and feedback, and finish with a documented, refreshable workflow. These topic areas summarize the section and are not a class-by-class syllabus.

Topic 01 · Sources & ETL

Data Sources, Profiling & the ETL Lifecycle

Know your data before you change it.

Start with the data lifecycle, a source inventory and a process map of how data moves from source to output. Profile spreadsheet and CSV files, including row counts, data types and missing values, so you understand what each field means and where it came from.

Core Activities

  • Data lifecycle and source inventory
  • Process mapping from source to prepared output
  • Extract, transform and load (ETL) concepts
  • Profiling row counts, data types and missing values
  • Understanding what each field means and where it came from

Labs & Tools

  • Microsoft Excel
  • Spreadsheet and CSV source files
  • Business brief and starter files
  • Source inventory and profiling checks
ETLData LifecycleData ProfilingProcess MappingCSV
Topic 02 · Power Query

Data Import & Repeatable Power Query Workflows

Build steps you can run again.

Import spreadsheet and CSV data into Power Query and record each preparation step so the workflow can be repeated. Required exercises use file-based sources, so this section can be completed before learning SQL.

Core Activities

  • Importing spreadsheet and CSV files
  • Building repeatable Power Query steps
  • Correcting data types
  • Keeping every transformation in a refreshable query
  • File-based exercises that require no SQL

Labs & Tools

  • Excel with Power Query
  • Spreadsheet files
  • CSV files
  • Source files supplied to individual enrollees
Power QueryImportData TypesRepeatable WorkflowsNo SQL Needed
Topic 03 · Cleaning

Cleaning, Standardization & Transformation Documentation

Fix it once, and write down how.

Standardize values and handle duplicates or missing records using documented rules. Every change to the data is recorded so others can see what was changed and why.

Core Activities

  • Standardizing values and categories
  • Managing duplicate records with documented rules
  • Handling missing records
  • Correcting data types
  • Documenting each transformation step

Labs & Tools

  • Power Query transformation steps
  • Microsoft Excel
  • Documented cleaning rules
  • Section datasets and starter files
Data CleaningStandardizationDuplicatesMissing ValuesDocumentation
Topic 04 · Merge & Reconcile

Merging, Appending & Data Reconciliation

Combine files without losing the numbers.

Merge related tables using keys and append compatible files. Then reconcile input and output totals to confirm that the prepared result still matches the sources.

Core Activities

  • Merging related tables using keys
  • Appending compatible files
  • Reconciling input and output totals
  • Checking the prepared result against business rules
  • Investigating and explaining differences

Labs & Tools

  • Power Query merge and append
  • Microsoft Excel
  • Reconciliation checks
  • Source and output totals
MergeAppendKeysReconciliationTotals
Topic 05 · Quality & Docs

Data Quality Rules, Exception Reporting & Data Dictionaries

Make reliability visible.

Apply completeness, validity, consistency and uniqueness checks, and record the exceptions they find. Create a simple data dictionary so every field has a clear meaning and source.

Core Activities

  • Completeness, validity, consistency and uniqueness checks
  • Recording and reporting exceptions
  • Creating a simple data dictionary
  • Documenting business rules
  • Mapping the path from source to output

Labs & Tools

  • Microsoft Excel
  • Power Query
  • Data dictionary
  • Exception report
Data QualityException ReportData DictionaryBusiness RulesValidation
Topic 06 · Refresh & Handoff

Workflow Refresh, Validation & Handoff Documentation

Hand over work a colleague can run.

Refresh your workflow with another period’s data, test the result and document how it runs. The section finishes with your certificate project: a refreshable ETL workflow with prepared output, data dictionary, process map, reconciliation checks, exception report and rerun instructions.

Core Activities

  • Refreshing the workflow with another period’s data
  • Testing and verifying the refreshed output
  • Documenting sources, transformations and handoff steps
  • Writing instructions for rerunning the workflow
  • Demonstrating the workflow and explaining key decisions

Labs & Tools

  • Excel with Power Query
  • Refreshable ETL workflow
  • Rerun instructions
  • Certificate assessment

FAQ

Questions we hear most.

Do I need SQL or programming experience?

No. This section needs comfort with tables, spreadsheet files and basic Excel operations. Required exercises use file-based sources, so no prior SQL or programming is needed.

How long is the course?

Four weeks: eight live meetings, held twice each week for 2 to 3 hours each, for 16 to 24 live instructional hours in total.

How many hours per week should I plan for?

Besides the two live meetings, plan for a recommended 3 to 5 hours of independent practice each week.

What will I learn?

You will learn extraction, transformation and loading (ETL) with spreadsheet and CSV sources: profiling data, correcting data types, standardizing values, combining files, applying quality checks and documenting every step in repeatable Power Query workflows.

What will I build?

A refreshable ETL workflow with prepared output, a data dictionary, a process map, reconciliation checks, an exception report and instructions for rerunning the workflow.

Which software do I need?

Excel with Power Query. Individual enrollees receive the source files and introductory preparation needed for the section. Enrollment materials will state any additional software arrangements.

How much does it cost?

Tuition for this individual four-week section is $1,000. The complete 16-week Business & Data Analyst Career Launch Bootcamp is $3,000, which saves $1,000 (25%) compared with buying all four sections separately for $4,000.

Is this section part of a larger program?

Yes. It is Weeks 5 to 8 of the 16-week bootcamp, alongside sections on Excel, SQL and Power BI. You can enroll in this section on its own or take the complete bootcamp.

Do I get a certificate?

Yes. You earn the Certificate in Data Engineering Foundations after you complete the required practical exercises, submit the section project, meet the published assessment criteria and demonstrate your work.

What kinds of roles are related to these skills?

Job-search directions include data quality assistant, data operations support, data preparation assistant and data stewardship support, as well as reporting preparation within an existing role. The certificate does not guarantee a job.

What if I'm still not sure?

That is what the free consultation is for. An advisor can talk through your background, the schedule and whether this section is the right fit.
